GradatiON is a personal Android chat client for Large Language Models — OpenRouter in the cloud and Ollama, LM Studio, llama.cpp, MLX LM, or Hermes Agent on your LAN.

• Multi-model chat with streaming, vision, and image generation where supported
• History with autosave, search, pin, rename, import/export
• System messages, presets, reasoning, and optional tool calling
• Dark monochrome UI with GradatiON branding
• On-device PDF export and markdown rendering
• No trackers, analytics, or ads

Fork of oxproxion (Apache 2.0). Not affiliated with xAI or OpenRouter.

Get an OpenRouter API key or point LAN settings at your own server. See in-app Help for the full guide.
